# TRAVELTROOP

Responsive editorial travel discovery and trip-planning landing page built with React, TypeScript and Vite.

## Run locally

```sh
npm install
npm run dev
```

Production build: `npm run build`.

Photography and Newsreader/Courier Prime typefaces are loaded from Unsplash and Google Fonts.

## Publish with GitHub Pages

Put the contents of this folder at the root of a GitHub repository, with the default branch named `main`. The included GitHub Actions workflow builds and publishes the site on each push. In the repository, open **Settings → Pages** and choose **GitHub Actions** as the build and deployment source. The live address will appear in the workflow's deployment result.
